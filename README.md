# AgriConnect AI

## Smart Farmer-to-Customer Marketplace

AgriConnect AI is a full-stack AI-powered marketplace that directly connects verified farmers with customers.

## Tech Stack

- React.js
- Python
- Django REST Framework
- MySQL
- Scikit-learn
- JWT
- Razorpay
- Git/GitHub

## Main Features

- Farmer registration
- Customer registration
- Farmer KYC verification
- Farm management
- Product marketplace
- Cart and orders
- Online payments
- Pre-orders
- Delivery tracking
- Reviews and ratings
- AI demand prediction
- AI price recommendation
- Admin dashboard
